
# JavaScript Practice

A collection of JavaScript exercises focused on learning and practicing core JavaScript concepts.

## Exercises

- `addNumber.js` — Working with numbers
- `calculateAverage.js` — Calculating averages
- `calculator.js` — Basic calculator
- `flight.js` — Flight and passenger management
- `password.js` — Password exercise
- `rockPaperScissors.js` — Rock, paper, scissors
- `season.js` — Seasons exercise

## Technologies

- JavaScript
- Node.js

## How to Run

Make sure Node.js is installed.

Run an exercise from the project directory:

```bash
node flight.js
```
